# BuildX Android App

تطبيق BuildX هو تطبيق محادثة ذكاء اصطناعي للأندرويد يتيح للمستخدمين التفاعل مع مساعد ذكي شخصي.

## الميزات الرئيسية

- **واجهة مستخدم عربية**: تطبيق كامل باللغة العربية مع دعم RTL
- **محادثة ذكية**: التفاعل مع مساعد ذكي يمكنه الإجابة على الأسئلة وتقديم المساعدة
- **وضع داكن/فاتح**: دعم كامل للوضعين الداكن والفاتح
- **تجربة مستخدم سلسة**: تصميم حديث وسهل الاستخدام
- **تخصيص**: إمكانية تخصيص التطبيق حسب احتياجات المستخدم

## هيكل التطبيق

- **شاشة البداية (Splash)**: شاشة ترحيبية تظهر عند بدء التطبيق
- **شاشة التعريف (Onboarding)**: شاشات تعريفية للمستخدمين الجدد
- **تسجيل الدخول**: شاشة تسجيل الدخول للمستخدمين
- **الشاشة الرئيسية**: تحتوي على أربعة أقسام رئيسية:
  - **الرئيسية**: عرض الميزات والمحادثات الأخيرة
  - **المحادثة**: واجهة المحادثة مع المساعد الذكي
  - **السجل**: سجل المحادثات السابقة
  - **الملف الشخصي**: إعدادات المستخدم والملف الشخصي

## المتطلبات التقنية

- Android Studio 4.2 أو أحدث
- Android SDK 21 أو أحدث
- Kotlin 1.7.10 أو أحدث
- Gradle 7.2.2 أو أحدث
